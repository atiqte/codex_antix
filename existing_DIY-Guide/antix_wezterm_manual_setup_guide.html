antiX Runit zzzFM-IceWM WezTerm Manual Setup Guide

Professional DIY guideline for installing, configuring, testing, updating, and safely using WezTerm manually while keeping ROXterm as the stable system default terminal on antiX inside VMware.

1. Design principle

This setup deliberately keeps ROXterm as x-terminal-emulator. WezTerm is installed and configured, but launched manually with wezterm or wezterm start.

Recommended final state: antiX remains compatible with existing IceWM, zzzFM, and antiX menu tools. WezTerm is available as an advanced optional terminal.
ComponentRecommended settingReason
System default terminal/usr/bin/roxtermMaximum antiX compatibility and minimum system change.
WezTerm launch methodwezterm or wezterm startManual use avoids breaking old x-terminal-emulator -e launchers.
Config location~/.config/wezterm/wezterm.luaUser-level, easy to back up, no root edit needed.
VMware display backendOpenGL, fallback SoftwareOpenGL is fast; Software is safer if VMware rendering glitches occur.
Do not set x-terminal-emulator to /usr/bin/open-wezterm-here for a stability-focused antiX setup. It may open WezTerm normally, but may fail traditional command execution such as x-terminal-emulator -e command.

2. Install WezTerm from the APT repository

Run this from ROXterm. It adds the WezTerm APT signing key and repository, updates APT, installs nala, then installs WezTerm.

Install WezTerm APT repository and package

curl -fsSL https://apt.fury.io/wez/gpg.key | sudo gpg --yes --dearmor -o /usr/share/keyrings/wezterm-fury.gpg
echo 'deb [signed-by=/usr/share/keyrings/wezterm-fury.gpg] https://apt.fury.io/wez/ * *' | sudo tee /etc/apt/sources.list.d/wezterm.list
sudo chmod 644 /usr/share/keyrings/wezterm-fury.gpg
sudo apt update
sudo apt install nala
sudo nala install wezterm

Verify installation

command -v wezterm
wezterm --version
apt policy wezterm

3. Keep ROXterm as the system default terminal

This is the key stability decision. WezTerm is installed, but x-terminal-emulator remains ROXterm.

Restore or keep ROXterm as x-terminal-emulator

sudo update-alternatives --set x-terminal-emulator /usr/bin/roxterm
update-alternatives --query x-terminal-emulator | grep -E 'Status:|Best:|Value:|Alternative:|Priority:'
readlink -f /etc/alternatives/x-terminal-emulator

Test that system default still opens ROXterm

x-terminal-emulator
x-terminal-emulator -e sh -lc 'echo "ROXterm default terminal test OK"; echo "Press Enter to close"; read dummy'
Expected result: readlink -f /etc/alternatives/x-terminal-emulator should show /usr/bin/roxterm.

4. Use WezTerm manually

Use one of these commands when you want WezTerm. This avoids changing antiX defaults.

Launch WezTerm manually

wezterm
wezterm start
wezterm start --cwd "$HOME"

5. Configure WezTerm

The configuration file is a Lua file that returns a configuration table. This config is optimized for antiX zzzFM-IceWM under VMware: X11 only, OpenGL with Software fallback, explicit theme, JetBrains Mono font, blinking I-beam cursor, visible scrollbar, moderate scrollback, and no built-in update checks.

Create config directory and backup old config

mkdir -p ~/.config/wezterm
[ -f ~/.config/wezterm/wezterm.lua ] && cp -a ~/.config/wezterm/wezterm.lua ~/.config/wezterm/wezterm.lua.bak.$(date +%F-%H%M%S) || true

Write ~/.config/wezterm/wezterm.lua

cat > ~/.config/wezterm/wezterm.lua <<'EOF'
local wezterm = require 'wezterm'
local config = wezterm.config_builder()

-- antiX zzzFM-IceWM under VMware should use X11, not Wayland.
config.enable_wayland = false

-- VMware-friendly rendering.
-- If you see black window, flicker, crashes, or rendering glitches, change "OpenGL" to "Software".
config.front_end = "OpenGL"

-- Explicit theme. This makes WezTerm independent from desktop light/dark theme detection.
-- If this scheme name is not recognized, use: "Builtin Solarized Dark"
config.color_scheme = "Night Owl (Gogh)"

-- Font.
config.font = wezterm.font "JetBrains Mono"
config.font_size = 11

-- Cursor: I-beam/bar cursor with blinking.
config.default_cursor_style = "BlinkingBar"
config.cursor_blink_rate = 700
config.cursor_thickness = "2px"

-- Keep animation modest for VMware/low-power laptop efficiency.
config.animation_fps = 10

-- Visible scrollbar.
config.enable_scroll_bar = true
config.colors = {
  scrollbar_thumb = "#5c6370",
}

-- Use login bash shell.
config.default_prog = { "/bin/bash", "-l" }

-- Window size.
config.initial_cols = 112
config.initial_rows = 30

-- Scrollback.
config.scrollback_lines = 10000

-- Tabs.
config.enable_tab_bar = true
config.hide_tab_bar_if_only_one_tab = false
config.mouse_wheel_scrolls_tabs = false

-- UX behavior.
config.window_close_confirmation = "NeverPrompt"
config.audible_bell = "Disabled"

-- Updates are handled by apt/nala, not by WezTerm itself.
config.check_for_updates = false

return config
EOF

6. Test WezTerm after configuration

Open and test WezTerm

wezterm
wezterm start --cwd "$HOME"

Check startup output for errors

wezterm 2>&1 | tee /tmp/wezterm-startup.log
grep -iE 'error|unknown|scheme|font|panic|failed' /tmp/wezterm-startup.log
The message about xdg-desktop-portal appearance detection is usually harmless on antiX/IceWM. This guide uses an explicit color scheme so WezTerm does not need a GNOME/KDE portal to determine light/dark appearance.

7. Troubleshooting

ProblemCauseFix
Black window, flicker, or rendering glitchesVMware graphics/OpenGL issueSwitch front_end from OpenGL to Software.
Color scheme errorScheme name not present in current WezTerm buildUse Builtin Solarized Dark.
Font does not look rightFont fallback or rendering differenceKeep JetBrains Mono or try DejaVu Sans Mono.
antiX menu item fails with -eYou changed x-terminal-emulator away from ROXtermRestore ROXterm as default using the command in section 3.

Fallback if OpenGL has rendering problems in VMware

sed -i 's/config.front_end = "OpenGL"/config.front_end = "Software"/' ~/.config/wezterm/wezterm.lua
wezterm

Fallback if Night Owl scheme is not recognized

sed -i 's/config.color_scheme = "Night Owl (Gogh)"/config.color_scheme = "Builtin Solarized Dark"/' ~/.config/wezterm/wezterm.lua
wezterm

8. Update WezTerm later

Because WezTerm was installed via APT, update it through nala/apt. Do not rely on WezTerm built-in update checking.

Update WezTerm later

sudo nala update
apt policy wezterm
sudo nala upgrade
wezterm --version

9. Rollback and cleanup

Use these only when needed.

Rollback only WezTerm config

ls -1 ~/.config/wezterm/wezterm.lua.bak.* 2>/dev/null
cp -a ~/.config/wezterm/wezterm.lua.bak.YYYY-MM-DD-HHMMSS ~/.config/wezterm/wezterm.lua

Remove WezTerm package but keep repository

sudo nala remove wezterm

Remove WezTerm package and repository

sudo nala remove wezterm
sudo rm -f /etc/apt/sources.list.d/wezterm.list
sudo rm -f /usr/share/keyrings/wezterm-fury.gpg
sudo apt update

Undo previous custom wrapper/default change

sudo update-alternatives --set x-terminal-emulator /usr/bin/roxterm
sudo update-alternatives --remove x-terminal-emulator /usr/local/bin/wezterm-x-terminal-emulator 2>/dev/null || true
sudo rm -f /usr/local/bin/wezterm-x-terminal-emulator
readlink -f /etc/alternatives/x-terminal-emulator

10. Final verification checklist

command -v wezterm
wezterm --version
readlink -f /etc/alternatives/x-terminal-emulator
test "$(readlink -f /etc/alternatives/x-terminal-emulator)" = "/usr/bin/roxterm" && echo "OK: ROXterm is still default"
wezterm
