Provider-Live Archive and Threshold Controller

Approval-gated local Maildir++ archiving for mbsync, Evolution, notmuch, and antiX IceWM.

Implementation and local safety tests completed 2026-07-11. antiX installation and real-mail runtime validation remain pending.
Start with Chunk 1. Run one chunk, paste its complete terminal output for review, and wait before continuing. Never start with prepare or cleanup.
  • Live tree: /mail/Mailstore/mbsync/provider-live
  • Archive tree: /mail/Mailstore/evolution/provider-live-archive
  • Evolution account: TAG-Mustang Local Archive
  • Threshold: 15,000 immediate root-INBOX files in cur plus new
  • Monitor: every 15 minutes, daily reminders, no automatic transfer or deletion
  • Archive folders: Inbox/YYYY/MM, represented as Maildir++ names such as .Inbox.2026.07
  • Target zero means all cutoff messages are removed after verification; later arrivals remain live.

Safety Contract

Every transaction audits the exact production mbsync policy. Normal folders must remain PullNew only. Sent may use only PullNew PushNew. Both channels must retain Remove None and Expunge None. Any PushGone, PullGone, flag synchronization, changed group membership, or changed live path blocks the transaction.

Approval 1 creates an immutable UID/hash manifest, a same-disk hard-link snapshot, a verified portable external package, and hash-verified monthly archive copies. Approval 2 is blocked until Evolution and notmuch validation are recorded. It reverifies the external package, tests one cleanup canary through mbsync, and only then removes manifest-selected local links.

Chunk 1: Read-Only antiX Discovery

This command does not install or modify anything.

antiX terminal
set -u

LIVE=/mail/Mailstore/mbsync/provider-live
ARCHIVE=/mail/Mailstore/evolution/provider-live-archive
CONFIG="$HOME/.config/notmuch/default/config"

echo "== system and storage =="
date -Is
cat /etc/os-release
df -hT /mail
findmnt -T /mail

echo "== live root INBOX =="
for d in "$LIVE/cur" "$LIVE/new"; do
  printf '%s=' "$d"
  find "$d" -maxdepth 1 -type f 2>/dev/null | wc -l
done
du -sh "$LIVE" 2>/dev/null || true

echo "== every provider-live tmp directory =="
find "$LIVE" -type d -name tmp -exec sh -c '
  for d do printf "%s files=" "$d"; find "$d" -maxdepth 1 -type f | wc -l; done
' sh {} + 2>/dev/null || true

echo "== proposed archive path =="
if [ -e "$ARCHIVE" ]; then
  ls -ld "$ARCHIVE"
  find "$ARCHIVE" -mindepth 1 -maxdepth 3 -printf '%y %p\n' | sed -n '1,120p'
else
  echo "archive_path=absent_expected_before_install"
fi

echo "== mbsync runtime =="
mbsync-provider-live-control status 2>&1 || true
pgrep -af 'mbsync|isync' || true
find /mail/AppData/isync -maxdepth 4 -type d -name lock -print 2>/dev/null || true

echo "== production mbsync block only; credentials excluded =="
awk '
  /^# BEGIN CODEX MBSYNC PROVIDER LIVE$/ {show=1}
  show {print}
  /^# END CODEX MBSYNC PROVIDER LIVE$/ {show=0}
' "$HOME/.config/isyncrc" 2>/dev/null || true

echo "== Evolution runtime and Maildir sources =="
flatpak ps 2>/dev/null || true
grep -RIl 'provider-live\|provider-live-archive' \
  "$HOME/.var/app/org.gnome.Evolution/config/evolution/sources" 2>/dev/null || true
grep -RInE 'BackendName=maildir|provider-live|provider-live-archive' \
  "$HOME/.var/app/org.gnome.Evolution/config/evolution/sources" 2>/dev/null || true

echo "== notmuch safety and current scope =="
if command -v notmuch >/dev/null 2>&1 && [ -f "$CONFIG" ]; then
  for key in database.path database.mail_root maildir.synchronize_flags index.decrypt new.ignore; do
    printf '%s=' "$key"
    notmuch --config="$CONFIG" config get "$key" 2>&1
  done
  printf 'messages='; notmuch --config="$CONFIG" count '*'
  printf 'files='; notmuch --config="$CONFIG" count --output=files '*'
  printf 'full_betterbird_indexed_files='
  notmuch --config="$CONFIG" search --output=files '*' | grep -c '^/mail/Mailstore/evolution/local-maildir/' || true
  printf 'provider_live_indexed_files='
  notmuch --config="$CONFIG" search --output=files '*' | grep -c '^/mail/Mailstore/mbsync/provider-live/' || true
fi
notmuch-browser-index-control status 2>&1 || true
notmuch-browser-control status 2>&1 || true

echo "== notification and external mount candidates =="
command -v notify-send || true
findmnt -rn -o TARGET,SOURCE,FSTYPE,OPTIONS | sed -n '1,160p'
for p in "/media/$USER" "/run/media/$USER" /mnt/hgfs; do
  [ ! -e "$p" ] || { echo "candidate=$p"; ls -la "$p" | sed -n '1,80p'; }
done
Stop here and review the output. All Maildir tmp counts must be zero, the production mbsync block must match the validated policy, and the full Betterbird archive must not be indexed.

Recovery and Retirement

Rollback missing captured live links
provider-live-archive-control rollback "$RUN_ID"

Keep the hard-link snapshot at least 30 days. Retirement reverifies the external package and every archive hash, then deletes only that run's same-disk snapshot.

After 30 days only
provider-live-archive-control retire-snapshot "$RUN_ID" \
  --approve-retire "$RUN_ID"
Never manually delete mbsync state, run manifests, monthly archive files, snapshot files, or external package parts while a run is active.
