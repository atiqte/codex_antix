# Ideas

This file is for possible future directions. Ideas listed here are not decisions and should not be implemented until moved into `docs/TODO.md` or recorded in `docs/DECISIONS.md`.

## Project Direction Ideas

- Decide whether this repository will become an application, script collection, automation project, documentation project, library, or experiment.
- Define the target user and main problem before choosing a technology stack.
- Keep the first implementation milestone small enough to review in one commit.

## Workflow Ideas

- Use GitHub or GitLab issues after a remote is connected.
- Add a lightweight project board once there are multiple active tasks.
- Add templates for issues or pull requests only if the workflow needs them.
