1. Confirmed Status

The Fedora conversion is treated as successful based on recorded converter verification and owner-reported Evolution GUI validation. The owner reported that mail_tagindustries_com_sg.Inbox opens with 14,279 emails, messages open, HTML renders correctly, and no error popup is shown.

This guide transports the converted canonical Maildir++ tree. It does not rerun the maildir-lite converter.

3. Export Files

The pack command creates one export folder containing:

  • manifest.json: the control file passed to every --manifest option.
  • inventory.jsonl: the per-file hash inventory, read automatically through the manifest.
  • maildirpp-archive.tar.gz.part0001, part0002, and so on.
Always pass manifest.json to --manifest. Keep inventory.jsonl beside it.

5. USB and Win11 Host-Share Transfer Workflow

Use this section after Fedora pack and Fedora verify-archive have passed for /home/atiq/maildirpp-archive-export-20260701-215204. The verified export is about 38G, contains 21 part files, and has a reconstructed archive stream of 40,613,836,495 bytes.

A flash drive with 50 GB free space is suitable for this verified export folder if the preflight space check passes. It is not suitable for the original uncompressed 59G Maildir++ tree.
Copy only /home/atiq/maildirpp-archive-export-20260701-215204. Do not copy /home/atiq/Evolution-Mailstore/betterbird-archive-maildirpp for this transfer. Do not unpack from the USB drive.

Step 5.1 - Preflight USB and Win11 host share

Replace only USB="/run/media/$USER/YOUR_USB_LABEL" with the real mounted USB path.

Fedora transfer preflight
set +e

export RUN="$HOME/codex-runs"
export SRC="/home/atiq/maildirpp-archive-export-20260701-215204"
export USB="/run/media/$USER/YOUR_USB_LABEL"
export HOST="/mnt/hgfs/Win11Host_Shared4VM"
export NEED_MARGIN_BYTES=$((2 * 1024 * 1024 * 1024))

echo "===== FEDORA TRANSFER PREFLIGHT START ====="
date

echo "===== PATH CHECK ====="
ls -ld "$RUN" "$SRC" "$USB" "$HOST"
df -h "$SRC" "$USB" "$HOST"
du -sh "$SRC"

echo "===== HOST SHARE MOUNT IDENTITY CHECK ====="
findmnt -T "$HOST" -o TARGET,SOURCE,FSTYPE,OPTIONS 2>/dev/null || true
host_fstype=$(findmnt -T "$HOST" -n -o FSTYPE 2>/dev/null | head -n 1)
host_target=$(findmnt -T "$HOST" -n -o TARGET 2>/dev/null | head -n 1)
echo "host_target=$host_target"
echo "host_fstype=$host_fstype"
case "$host_fstype" in
  fuse.vmhgfs-fuse|fuse.vmhgfs|vmhgfs|hgfs)
    echo "host_share_mount_ok=yes"
    ;;
  *)
    echo "host_share_mount_ok=no"
    ;;
esac

echo "===== EXPORT FILE CHECK ====="
test -f "$SRC/manifest.json"; echo "manifest_exit=$?"
test -f "$SRC/inventory.jsonl"; echo "inventory_exit=$?"
echo "part_count=$(find "$SRC" -maxdepth 1 -type f -name 'maildirpp-archive.tar.gz.part*' | wc -l)"
ls -lh "$SRC"/maildirpp-archive.tar.gz.part0001 "$SRC"/maildirpp-archive.tar.gz.part0021

echo "===== BYTE SPACE CHECK ====="
src_bytes=$(du -sb "$SRC" | awk '{print $1}')
need_bytes=$((src_bytes + NEED_MARGIN_BYTES))

for dst in "$USB" "$HOST"; do
  avail_bytes=$(df -PB1 "$dst" | awk 'NR==2 {print $4}')
  echo "dst=$dst"
  echo "src_bytes=$src_bytes"
  echo "need_bytes_with_2GiB_margin=$need_bytes"
  echo "avail_bytes=$avail_bytes"
  if [ "$avail_bytes" -ge "$need_bytes" ]; then
    echo "space_ok=yes"
  else
    echo "space_ok=no"
  fi
  probe_dir="$dst/.codex-write-test-$(date +%Y%m%d%H%M%S)-$$"
  mkdir "$probe_dir" 2>/dev/null
  write_probe_exit=$?
  echo "write_probe_exit=$write_probe_exit"
  if [ "$write_probe_exit" -eq 0 ]; then
    printf 'ok\n' > "$probe_dir/probe.txt"
    echo "write_file_exit=$?"
    rm -f "$probe_dir/probe.txt"
    rmdir "$probe_dir"
  fi
done

echo "===== SCRIPT CHECK ====="
test -f "$RUN/maildirpp_transport.py"; echo "maildirpp_script_exit=$?"
python3 -m py_compile "$RUN/maildirpp_transport.py"; echo "compile_exit=$?"

echo "===== FEDORA TRANSFER PREFLIGHT DONE ====="

Continue with USB only if manifest_exit=0, inventory_exit=0, part_count=21, the USB shows space_ok=yes, write_probe_exit=0, and write_file_exit=0, and compile_exit=0. Continue with the Win11 host-share copy only if it also shows host_share_mount_ok=yes, space_ok=yes, write_probe_exit=0, and write_file_exit=0.

Step 5.2 - Copy verified Fedora export to USB

Replace only USB="/run/media/$USER/YOUR_USB_LABEL" with the real mounted USB path.

Fedora USB copy
set +e

export RUN="$HOME/codex-runs"
export SRC="/home/atiq/maildirpp-archive-export-20260701-215204"
export USB="/run/media/$USER/YOUR_USB_LABEL"
export USB_EXPORT="$USB/maildirpp-archive-export-20260701-215204"
export USB_SCRIPTS="$USB/codex-runs"

echo "===== FEDORA USB COPY START ====="
date

mkdir -p "$USB_SCRIPTS" "$USB_EXPORT"

cp -av "$RUN/maildirpp_transport.py" "$RUN/betterbird_profile_transport.py" "$USB_SCRIPTS/"
sha256sum "$USB_SCRIPTS/maildirpp_transport.py" "$USB_SCRIPTS/betterbird_profile_transport.py"

if command -v rsync >/dev/null 2>&1; then
  rsync -rt --partial --info=progress2 "$SRC/" "$USB_EXPORT/"
  COPY_EXIT=$?
else
  cp -av "$SRC/." "$USB_EXPORT/"
  COPY_EXIT=$?
fi
echo "copy_exit=$COPY_EXIT"

sync

echo "===== USB COPY FILE CHECK ====="
test -f "$USB_EXPORT/manifest.json"; echo "usb_manifest_exit=$?"
test -f "$USB_EXPORT/inventory.jsonl"; echo "usb_inventory_exit=$?"
echo "usb_part_count=$(find "$USB_EXPORT" -maxdepth 1 -type f -name 'maildirpp-archive.tar.gz.part*' | wc -l)"
du -sh "$USB_EXPORT"

echo "===== VERIFY ARCHIVE ON USB ====="
python3 "$USB_SCRIPTS/maildirpp_transport.py" verify-archive \
  --manifest "$USB_EXPORT/manifest.json"
echo "usb_verify_archive_exit=$?"

echo "===== SYNC BEFORE UNPLUG ====="
sync
echo "If usb_verify_archive_exit=0, unmount/eject the USB safely before removing it."

echo "===== FEDORA USB COPY DONE ====="

Expected: copy_exit=0, usb_part_count=21, usb_verify_archive_exit=0, and status=ok.

Step 5.4 - Copy USB export to antiX staging

Replace only USB="/media/$USER/YOUR_USB_LABEL" with the real mounted USB path if different.

antiX USB staging copy
set +e

export USB="/media/$USER/YOUR_USB_LABEL"
export USB_EXPORT="$USB/maildirpp-archive-export-20260701-215204"
export USB_SCRIPTS="$USB/codex-runs"

export RUN="$HOME/codex-runs"
export TRANSFER="/mail/import-staging/maildirpp-archive-export-20260701-215204"

echo "===== ANTIX USB TO STAGING START ====="
date

echo "===== PATH CHECK ====="
echo "USB=$USB"
echo "USB_EXPORT=$USB_EXPORT"
echo "TRANSFER=$TRANSFER"

echo "===== COPY SCRIPTS TO ANTIX ====="
mkdir -p "$RUN"

echo "===== VERIFY USB ARCHIVE BEFORE STAGING COPY ====="
python3 "$RUN/maildirpp_transport.py" verify-archive \
  --manifest "$USB_EXPORT/manifest.json"
echo "usb_verify_archive_exit=$?"

echo "===== PREPARE STAGING DESTINATION ====="
mkdir -p /mail/import-staging

if [ -e "$TRANSFER" ] && [ "$(find "$TRANSFER" -mindepth 1 -maxdepth 1 -print -quit 2>/dev/null)" ]; then
  echo "ERROR: staging destination is not empty: $TRANSFER"
  echo "Stop here. Do not merge over an existing transfer folder."
  exit 50
fi

mkdir -p "$TRANSFER"

echo "===== COPY USB EXPORT TO ANTIX STAGING ====="
if command -v rsync >/dev/null 2>&1; then
  rsync -rt --partial --info=progress2 "$USB_EXPORT/" "$TRANSFER/"
  COPY_EXIT=$?
else
  cp -av "$USB_EXPORT/." "$TRANSFER/"
  COPY_EXIT=$?
fi

echo "copy_exit=$COPY_EXIT"
sync

echo "===== STAGING FILE CHECK ====="
test -f "$TRANSFER/manifest.json"; echo "staging_manifest_exit=$?"
test -f "$TRANSFER/inventory.jsonl"; echo "staging_inventory_exit=$?"
echo "staging_part_count=$(find "$TRANSFER" -maxdepth 1 -type f -name 'maildirpp-archive.tar.gz.part*' | wc -l)"

echo "===== VERIFY ARCHIVE FROM ANTIX STAGING ====="
python3 "$RUN/maildirpp_transport.py" verify-archive \
  --manifest "$TRANSFER/manifest.json"
echo "staging_verify_archive_exit=$?"

echo "===== ANTIX USB TO STAGING DONE ====="

Expected: usb_verify_archive_exit=0, copy_exit=0, staging_part_count=21, staging_verify_archive_exit=0, and status=ok.

8. Troubleshooting

ProblemAction
tmp-files-presentStop and inspect. A clean converted archive should have empty tmp/ directories.
Missing cur/new/tmpThe source is not a complete Maildir++ root or dot folder. Do not pack until fixed.
SHA256 mismatchRe-transfer the affected part or repack from Fedora if the source changed.
Destination not emptyUse a fresh destination. Do not merge archive trees by unpacking over old data.
Folders visible but no messagesRemove the Evolution account and recreate it as Maildir-format mail directories, not MH.
