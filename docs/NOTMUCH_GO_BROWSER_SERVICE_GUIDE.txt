# NOTMUCH BROWSER SERVICE - Go chi/HTMX/Tailwind DIY Guide for antiX

Updated: 2026-07-14
Validated platform: antiX Linux runit edition with zzzFM/IceWM
Host access: Windows 11 through an SSH local-forward tunnel

This is the complete rebuild and operating guide for the validated read-only
NOTMUCH BROWSER SERVICE. It supersedes the July 9 chi-only revision of this
guide.

The service uses:

- Go net/http and github.com/go-chi/chi/v5 v5.3.1.
- golang.org/x/net/html v0.57.0 for structured email HTML processing.
- Go module floor 1.25.0. The validated antiX build used Go 1.26.4.
- Server-rendered embedded templates.
- Local HTMX, compiled local Tailwind CSS, a tiny local app.js, and local
  Lucide icons.
- notmuch as the only search/index backend.
- IceWM user-session startup plus a lock-aware 60-second notmuch refresh loop.
- SSH tunneling for Windows access; the HTTP listener remains localhost-only.

No full repository clone, CDN, npm runtime, Node runtime, React, Gin, Flask,
uv runtime, Material UI package, tmux supervisor, or remote-image proxy is
required on antiX.

-------------------------------------------------------------------------------
1. Scope and security model
-------------------------------------------------------------------------------

Browser routes:

- GET /
- GET /search?q=&offset=&limit=
- GET /message?id=&dup=&images=blocked|embedded|remote
- GET /attachment?cap=...
- GET /attachments.zip?cap=...
- GET /inline-image?cap=...
- GET /status
- GET /healthz
- GET /static/*

The service does not edit Maildir files, notmuch tags, or the notmuch database.
Evolution remains the application for reply, forward, compose, and send.

Attachment and image rules:

- Each attachment/image URL is protected by a process-lifetime HMAC-SHA256
  capability. Old capabilities expire when the service restarts.
- Individual downloads and Save All always use the selected duplicate.
- Save All uses ZIP Store mode and safe, collision-resolved base filenames.
- Initial HTML mode blocks every image.
- "Show embedded images" enables only CID/data/local message images after a
  confirmation.
- "Load remote images" requires a second confirmation. The browser, not the Go
  service, contacts the remote server.
- HTML stays in an iframe with sandbox and referrerpolicy=no-referrer.
- SVG is served as an image with a separate restrictive CSP; it is never placed
  directly in the parent DOM.
- PNG, JPEG, GIF, WebP, BMP, SVG, CID, and data images can render. TIFF, HEIC,
  and other unsupported browser formats remain downloadable.

Default resource limits:

- 2 concurrent inline-image operations.
- 1 concurrent individual/ZIP download.
- 64 MiB per inline image.
- 512 MiB per attachment.
- 200 attachments and 2 GiB decoded output per Save All ZIP.
- 2-minute inline-image timeout.
- 15-minute attachment/ZIP timeout.
- Temporary output: /mail/AppData/notmuch-browser/download-tmp, directory mode
  0700 and files mode 0600. Successful and failed requests remove their files;
  startup removes files older than 24 hours.

7. Chunk A3 - Backup and atomic installation
-------------------------------------------------------------------------------

Run only after Chunk A2 passes. This chunk keeps a dated copy of any installed
artifacts. It does not modify mail or notmuch tags.

```sh
set -eu

STAGE="$HOME/notmuch-browser-stage"
BIN_DIR="$HOME/.local/bin"
STAMP="$(date +%Y%m%d-%H%M%S)"
BACKUP="/mail/Backups/notmuch-browser/$STAMP-before-install"
STATE="/mail/AppData/notmuch-browser"
LOGS="/mail/Logs/notmuch-browser"
MBSYNC_LOCK="/mail/AppData/isync/provider-live-loop/lock"

test -x "$STAGE/notmuch-browser"
test -x "$STAGE/notmuch-browser-control"
test -x "$STAGE/notmuch-browser-index-control"

mkdir -p "$BIN_DIR" "$BACKUP" "$STATE/download-tmp" "$LOGS"
chmod 700 "$STATE" "$STATE/download-tmp" "$LOGS" "$BACKUP"

for name in notmuch-browser notmuch-browser-control notmuch-browser-index-control; do
  if [ -f "$BIN_DIR/$name" ]; then
    cp -p "$BIN_DIR/$name" "$BACKUP/$name"
    : > "$BACKUP/.had-$name"
  fi
done
[ ! -f "$HOME/.icewm/startup" ] ||
  cp -p "$HOME/.icewm/startup" "$BACKUP/icewm-startup"
cp -p "$HOME/.config/notmuch/default/config" "$BACKUP/notmuch-config"
sha256sum "$BACKUP"/* > "$BACKUP/SHA256SUMS"
printf '%s\n' "$BACKUP" > "$STATE/latest-install-backup"
chmod 600 "$STATE/latest-install-backup"

if command -v mbsync-provider-live-control >/dev/null 2>&1; then
  mbsync-provider-live-control status > "$BACKUP/mbsync-before.txt" 2>&1 || true
  if grep -Fqx 'paused=no' "$BACKUP/mbsync-before.txt"; then
    MBSYNC_WAS_UNPAUSED=yes
    mbsync-provider-live-control pause
  fi
fi
if [ -x "$BIN_DIR/notmuch-browser-index-control" ]; then
  "$BIN_DIR/notmuch-browser-index-control" stop || true
fi
if [ -x "$BIN_DIR/notmuch-browser-control" ]; then
  "$BIN_DIR/notmuch-browser-control" stop || true
fi

i=0
while [ -d "$MBSYNC_LOCK" ] && [ "$i" -lt 80 ]; do
  i=$((i + 1))
  sleep 2
done
test ! -d "$MBSYNC_LOCK"

rollback_failed_install() {
  rc=$?
  [ "$rc" -ne 0 ] || return 0
  trap - EXIT HUP INT TERM
  set +e
  [ ! -x "$BIN_DIR/notmuch-browser-index-control" ] ||
    "$BIN_DIR/notmuch-browser-index-control" stop
  [ ! -x "$BIN_DIR/notmuch-browser-control" ] ||
    "$BIN_DIR/notmuch-browser-control" stop
  for name in notmuch-browser notmuch-browser-control notmuch-browser-index-control; do
    if [ -f "$BACKUP/.had-$name" ]; then
      install -m 700 "$BACKUP/$name" "$BIN_DIR/$name"
    else
      rm -f "$BIN_DIR/$name"
    fi
  done
  if [ -f "$BACKUP/.had-notmuch-browser-control" ] &&
     [ -f "$BACKUP/.had-notmuch-browser" ]; then
    "$BIN_DIR/notmuch-browser-control" start
  fi
  if [ -f "$BACKUP/.had-notmuch-browser-index-control" ]; then
    "$BIN_DIR/notmuch-browser-index-control" start
  fi
  if [ "$MBSYNC_WAS_UNPAUSED" = yes ]; then
    mbsync-provider-live-control resume
  fi
  echo "status=automatic_rollback_complete failed_rc=$rc"
  exit "$rc"
}
trap rollback_failed_install EXIT HUP INT TERM

install -m 700 "$STAGE/notmuch-browser" "$BIN_DIR/.notmuch-browser.new"
install -m 700 "$STAGE/notmuch-browser-control" \
  "$BIN_DIR/.notmuch-browser-control.new"
install -m 700 "$STAGE/notmuch-browser-index-control" \
  "$BIN_DIR/.notmuch-browser-index-control.new"

mv -f "$BIN_DIR/.notmuch-browser.new" "$BIN_DIR/notmuch-browser"
mv -f "$BIN_DIR/.notmuch-browser-control.new" \
  "$BIN_DIR/notmuch-browser-control"
mv -f "$BIN_DIR/.notmuch-browser-index-control.new" \
  "$BIN_DIR/notmuch-browser-index-control"

sha256sum "$BIN_DIR/notmuch-browser" \
  "$BIN_DIR/notmuch-browser-control" \
  "$BIN_DIR/notmuch-browser-index-control"

"$BIN_DIR/notmuch-browser-control" start
"$BIN_DIR/notmuch-browser-index-control" start

sleep 2
"$BIN_DIR/notmuch-browser-control" status
"$BIN_DIR/notmuch-browser-index-control" status
curl -fsS http://127.0.0.1:8765/healthz > /tmp/notmuch-browser-health.json
cat /tmp/notmuch-browser-health.json
grep -F '"ok":true' /tmp/notmuch-browser-health.json
grep -F '"read_only":true' /tmp/notmuch-browser-health.json
grep -F '"mail_mutation":false' /tmp/notmuch-browser-health.json
grep -F '"downloads_enabled":true' /tmp/notmuch-browser-health.json
grep -F '"temporary_download_files":true' /tmp/notmuch-browser-health.json
if [ "$MBSYNC_WAS_UNPAUSED" = yes ]; then
  mbsync-provider-live-control resume
fi
trap - EXIT HUP INT TERM
echo
echo "backup=$BACKUP"
echo 'status=atomic_install_complete'
```

Expected idle status includes:

  loop=running
  download_tmp_files=0
  download_tmp_bytes=0
  mbsync_lock=absent
  refresh_lock=absent

11. Chunk A7 - Stable read-only before/after proof
-------------------------------------------------------------------------------

This is the strongest portable proof available without the private production
sample map. It pauses mbsync and stops the index loop so legitimate background
changes cannot be mistaken for browser mutation. The cleanup trap restores both.

Run the chunk, perform search/view/download/Save All/embedded/remote checks when
it pauses, return to the terminal, and press Enter.

```sh
set -eu

CONFIG="$HOME/.config/notmuch/default/config"
RUN="$HOME/codex-runs/notmuch-browser-readonly-$(date +%Y%m%d-%H%M%S)"
mkdir -p "$RUN"
INDEX_WAS_RUNNING=no
MBSYNC_WAS_UNPAUSED=no

notmuch-browser-index-control status > "$RUN/index-before.txt" 2>&1 || true
if grep -Fqx 'loop=running' "$RUN/index-before.txt"; then
  INDEX_WAS_RUNNING=yes
fi

if command -v mbsync-provider-live-control >/dev/null 2>&1; then
  mbsync-provider-live-control status > "$RUN/mbsync-before.txt" 2>&1 || true
  if grep -Fqx 'paused=no' "$RUN/mbsync-before.txt"; then
    MBSYNC_WAS_UNPAUSED=yes
    mbsync-provider-live-control pause
  fi
fi

cleanup() {
  if [ "$INDEX_WAS_RUNNING" = yes ]; then
    notmuch-browser-index-control start >/dev/null 2>&1 || true
  fi
  if [ "$MBSYNC_WAS_UNPAUSED" = yes ]; then
    mbsync-provider-live-control resume >/dev/null 2>&1 || true
  fi
}
trap cleanup EXIT HUP INT TERM

notmuch-browser-index-control stop || true

i=0
while { [ -d /mail/AppData/isync/provider-live-loop/lock ] ||
        [ -d /mail/AppData/notmuch-browser/index-refresh.lock ]; } &&
      [ "$i" -lt 80 ]; do
  i=$((i + 1))
  sleep 2
done
test ! -d /mail/AppData/isync/provider-live-loop/lock
test ! -d /mail/AppData/notmuch-browser/index-refresh.lock

snapshot() {
  label="$1"
  {
    notmuch --config="$CONFIG" count '*' | sed 's/^/messages=/'
    notmuch --config="$CONFIG" count --output=files '*' | sed 's/^/files=/'
    notmuch --config="$CONFIG" count tag:inbox | sed 's/^/inbox=/'
    notmuch --config="$CONFIG" search --output=files '*' |
      LC_ALL=C sort | sha256sum | sed 's/^/indexed_paths_sha256=/'
    notmuch --config="$CONFIG" dump --format=batch-tag '*' |
      sha256sum | sed 's/^/tags_sha256=/'
    find /mail/Mailstore -type f -printf '%P\0%s\0%T@\0' 2>/dev/null |
      LC_ALL=C sort -z | sha256sum | sed 's/^/mailstore_metadata_sha256=/'
    find /mail/Mailstore -type f -path '*/tmp/*' 2>/dev/null |
      wc -l | sed 's/^/maildir_tmp_files=/'
    find /mail/AppData/notmuch-browser/download-tmp -maxdepth 1 \
      -type f -name 'nmb-*' 2>/dev/null |
      wc -l | sed 's/^/download_tmp_files=/'
  } > "$RUN/$label.txt"
  cat "$RUN/$label.txt"
}

echo '===== BEFORE ====='
snapshot before
printf '%s\n' \
  'Use the browser now: search, open messages, switch duplicates, download one' \
  'attachment, Save All, confirm embedded images, optionally confirm remote' \
  'images, then wait for downloads to finish and return here.'
printf 'Press Enter to capture AFTER: '
read answer

echo '===== AFTER ====='
snapshot after
diff -u "$RUN/before.txt" "$RUN/after.txt"
grep -Fqx 'maildir_tmp_files=0' "$RUN/after.txt"
grep -Fqx 'download_tmp_files=0' "$RUN/after.txt"

echo 'strict_snapshot_match=yes'
echo 'mail_and_index_mutation=no'
echo 'download_temp_cleanup=verified'
echo "log_dir=$RUN"

cleanup
trap - EXIT HUP INT TERM
notmuch-browser-control status
notmuch-browser-index-control status
echo 'status=readonly_proof_complete'
```

On the original validated VM, the pre-attachment rollback is:

```sh

```

For a recreated VM, Chunk A3 prints and records its dated backup in:

  /mail/AppData/notmuch-browser/latest-install-backup

To restore those saved binaries manually:

```sh
set -eu

BACKUP="$(cat /mail/AppData/notmuch-browser/latest-install-backup)"
BIN_DIR="$HOME/.local/bin"
test -d "$BACKUP"
sha256sum -c "$BACKUP/SHA256SUMS"

[ ! -x "$BIN_DIR/notmuch-browser-index-control" ] ||
  "$BIN_DIR/notmuch-browser-index-control" stop || true
[ ! -x "$BIN_DIR/notmuch-browser-control" ] ||
  "$BIN_DIR/notmuch-browser-control" stop || true

for name in notmuch-browser notmuch-browser-control notmuch-browser-index-control; do
  if [ -f "$BACKUP/$name" ]; then
    install -m 700 "$BACKUP/$name" "$BIN_DIR/$name"
  fi
done

"$BIN_DIR/notmuch-browser-control" start
"$BIN_DIR/notmuch-browser-index-control" start
curl -fsS http://127.0.0.1:8765/healthz
echo
echo 'status=rollback_complete'
```

If Chunk A3 was a first-ever install and the backup contains no older binaries,
stop the new service and remove only the three installed browser artifacts after
reviewing their paths. Never remove Maildir, notmuch database, config, state, or
logs as part of application rollback.

15. Stale notmuch path repair
-------------------------------------------------------------------------------

Symptom:

  Error opening /mail/Mailstore/.../new/...: No such file or directory

Cause: mbsync moved or renamed Maildir files after the last notmuch refresh.
This is not a chi, HTMX, Tailwind, download, or rendering failure.

Repair:

```sh
set -eu

if [ -d /mail/AppData/isync/provider-live-loop/lock ]; then
  echo 'mbsync is active; wait and rerun'
  exit 0
fi

notmuch-browser-control refresh-index
notmuch-browser-control status
curl -fsS 'http://127.0.0.1:8765/search?q=tag%3Ainbox&offset=0&limit=10' \
  > /tmp/notmuch-browser-search-after-refresh.html
wc -c /tmp/notmuch-browser-search-after-refresh.html
find /mail/Mailstore -type f -path '*/tmp/*' 2>/dev/null |
  wc -l | sed 's/^/maildir_tmp_files=/'
```

The automatic index loop normally prevents recurrence by refreshing every 60
seconds without overlapping mbsync.

16. Troubleshooting
-------------------------------------------------------------------------------

Service does not start:
- Run notmuch-browser-control logs.
- Confirm all four notmuch safety values match Section 5.
- Confirm port 8765 is not already occupied:
  ss -ltnp | grep ':8765'
- Confirm /mail/AppData/notmuch-browser and /mail/Logs/notmuch-browser are
  writable by atiq and mode 0700.

Health is good but search reports missing files:
- Use Section 15. Do not reinstall the browser.

Download returns 403:
- Refresh the message page. Capabilities intentionally expire after service
  restart and are bound to route purpose, message, duplicate, part, filename,
  and media type.

Download returns 413:
- The decoded part or ZIP exceeded the configured safety limit. Download
  supported parts individually; do not raise limits without reviewing VM disk
  capacity and threat model.

Download returns 429:
- Another download/ZIP occupies the single bounded slot. Wait for it to finish.

Download returns 502 or 504:
- Inspect browser logs. 502 means notmuch failed; 504 means the bounded command
  timed out. Check disk, source file existence, and index freshness.

Temporary files are nonzero while idle:
- Confirm no download is still active.
- Run notmuch-browser-control status and logs.
- Do not manually delete active nmb-* files.
- After stopping the browser, files older than 24 hours can be reviewed; normal
  startup cleanup removes them.

Embedded images do not render:
- Confirm "Show embedded images" was accepted for the current message and
  duplicate.
- Confirm the format is browser-native. TIFF/HEIC remain downloads.
- Reloading or changing duplicate intentionally resets permission.

Remote images do not render:
- Embedded permission must be accepted first.
- The second confirmation allows direct browser HTTP/HTTPS requests. Proxy,
  DNS, firewall, or sender-server behavior can still prevent display.
- The Go service never fetches remote images.

Terminal closes before output can be copied:
- Run chunks from an already-open terminal, not a launcher configured to close.
- Capture output and locate the newest log:

```sh
~/codex-runs/codex-batch.sh 2>&1 | tee \
  ~/codex-runs/codex-batch-$(date +%Y%m%d-%H%M%S).log

ls -lt ~/codex-runs/*.log | head
```

- Reopen it with: less /path/to/the/newest.log

"unexpected EOF while looking for matching backtick":
- The saved shell file was truncated or a Markdown fence/backtick was copied.
  Run sh -n FILE, inspect the first error line, and replace the whole command
  file from a clean raw block. Do not patch a batch script with commands stored
  inside that same batch script.

"corrected probe count is not one":
- A self-patch guard found unexpected content. Preserve the failed file and
  create a complete corrected script at a separate stable filename.

Pipeline says a running loop is stopped:
- Under pipefail, producer | grep -q can fail after grep exits early. Capture
  complete status to a file first, then grep the file, as Chunk A7 does.

"/proc/PID/cmdline: No such file":
- This can occur when a process exits between two checks. It is harmless only if
  stop then reports loop=stopped and final restoration reports loop=running.

Python validator IndexError:
- The validated private production validator requires exactly three arguments:
  base URL, audit JSON path, and run directory. It is validation evidence, not
  part of the 30-member rebuild bundle.

Windows says ANTI_X_VM_IP cannot be resolved:
- ANTI_X_VM_IP is a placeholder. Use the numeric result from hostname -I, such
  as 192.168.254.128.

Windows port forwarding fails:
- Check Test-NetConnection VM_IP -Port 22.
- Keep the ssh -N terminal open.
- If local 8765 is occupied, forward 8876 to antiX 8765.
