Converted Maildir++ Archive Transport Guide
===========================================

Purpose
-------

This guide moves the already-converted canonical Maildir++ Betterbird archive
from Fedora to antiX.

It does not rerun the maildir-lite converter.
It does not use the mbsync live tree.
It keeps the converted archive separate from provider-live.

Confirmed Fedora status:

- Converter hash verification previously passed.
- Owner reported Evolution GUI validation on Fedora:
  - mail_tagindustries_com_sg.Inbox opens.
  - The folder shows 14,279 emails.
  - Messages open.
  - HTML renders correctly.
  - No error popup is shown.


Important Paths
---------------

Fedora converted source:

  /home/atiq/Evolution-Mailstore/betterbird-archive-maildirpp

antiX final target:

  /mail/Mailstore/evolution/local-maildir

antiX transfer staging folder for the verified export package:

  /mail/import-staging/maildirpp-archive-export-20260701-215204

Keep separate from:

  /mail/Mailstore/mbsync/provider-live


Tool
----

Use:

  src/maildirpp_transport.py

The tool creates:

  manifest.json
  inventory.jsonl
  maildirpp-archive.tar.gz.part0001
  maildirpp-archive.tar.gz.part0002
  ...

Every --manifest option points to:

  manifest.json

inventory.jsonl must stay beside manifest.json, but it is read automatically.


Safety Rules
------------

- Stop Evolution on Fedora before packing.
- Pack only the converted Maildir++ tree.
- Do not pack the original Betterbird profile for this step.
- Do not unpack over an existing non-empty antiX target.
- A clean converted archive should have empty tmp directories.
- Symlinks and special files are refused by default.
- Do not choose MH-format mail directories in Evolution.
- Add the restored archive as Maildir-format mail directories.


Fedora Workflow
===============

Step 1 - Set paths
------------------

COPY COMMAND:

  export REPO="$HOME/antiX_VM_Laptop"
  export SOURCE="/home/atiq/Evolution-Mailstore/betterbird-archive-maildirpp"
  export EXPORT="$HOME/maildirpp-archive-export-$(date +%Y%m%d-%H%M%S)"


Step 2 - Stop Evolution and background services
-----------------------------------------------

COPY COMMAND:

  flatpak kill org.gnome.Evolution 2>/dev/null || true
  pkill -u "$USER" -f 'evolution|evolution-source-registry|evolution-addressbook-factory|evolution-calendar-factory' 2>/dev/null || true
  sleep 3
  pgrep -fa 'evolution|org.gnome.Evolution|bwrap' || true

If Evolution processes remain, stop them before continuing.


Step 3 - Inspect the converted Maildir++ source
-----------------------------------------------

COPY COMMAND:

  cd "$REPO"
  python3 src/maildirpp_transport.py inspect \
    --source "$SOURCE"

Expected:

  mode=inspect
  tmp_files=0
  status=ok

If tmp_files is not 0, stop and inspect. A finished converted archive should
not have payload files in tmp directories.


Step 4 - Pack the converted Maildir++ archive
---------------------------------------------

COPY COMMAND:

  cd "$REPO"
  python3 src/maildirpp_transport.py pack \
    --source "$SOURCE" \
    --out "$EXPORT"

Expected:

  mode=pack
  parts=...
  cur_files=...
  new_files=...
  tmp_files=0
  status=ok


Step 5 - Confirm export files
-----------------------------

COPY COMMAND:

  ls -lh "$EXPORT"
  test -f "$EXPORT/manifest.json"
  test -f "$EXPORT/inventory.jsonl"
  ls "$EXPORT"/maildirpp-archive.tar.gz.part*

Transfer the whole export folder to antiX. Keep all filenames unchanged.

Fedora Transfer Preflight - Check USB and Win11 host share
----------------------------------------------------------

Replace only this value with the real mounted USB path:

  USB="/run/media/$USER/YOUR_USB_LABEL"

The Win11 host-share path is expected to be:

  /mnt/hgfs/Win11Host_Shared4VM

COPY COMMAND:

  set +e

  export RUN="$HOME/codex-runs"
  export SRC="/home/atiq/maildirpp-archive-export-20260701-215204"
  export USB="/run/media/$USER/YOUR_USB_LABEL"
  export HOST="/mnt/hgfs/Win11Host_Shared4VM"
  export NEED_MARGIN_BYTES=$((2 * 1024 * 1024 * 1024))

  echo "===== FEDORA TRANSFER PREFLIGHT START ====="
  date

  echo "===== PATH CHECK ====="
  ls -ld "$RUN" "$SRC" "$USB" "$HOST"
  df -h "$SRC" "$USB" "$HOST"
  du -sh "$SRC"

  echo "===== HOST SHARE MOUNT IDENTITY CHECK ====="
  findmnt -T "$HOST" -o TARGET,SOURCE,FSTYPE,OPTIONS 2>/dev/null || true
  host_fstype=$(findmnt -T "$HOST" -n -o FSTYPE 2>/dev/null | head -n 1)
  host_target=$(findmnt -T "$HOST" -n -o TARGET 2>/dev/null | head -n 1)
  echo "host_target=$host_target"
  echo "host_fstype=$host_fstype"
  case "$host_fstype" in
    fuse.vmhgfs-fuse|fuse.vmhgfs|vmhgfs|hgfs)
      echo "host_share_mount_ok=yes"
      ;;
    *)
      echo "host_share_mount_ok=no"
      ;;
  esac

  echo "===== EXPORT FILE CHECK ====="
  test -f "$SRC/manifest.json"; echo "manifest_exit=$?"
  test -f "$SRC/inventory.jsonl"; echo "inventory_exit=$?"
  echo "part_count=$(find "$SRC" -maxdepth 1 -type f -name 'maildirpp-archive.tar.gz.part*' | wc -l)"
  ls -lh "$SRC"/maildirpp-archive.tar.gz.part0001 "$SRC"/maildirpp-archive.tar.gz.part0021

  echo "===== BYTE SPACE CHECK ====="
  src_bytes=$(du -sb "$SRC" | awk '{print $1}')
  need_bytes=$((src_bytes + NEED_MARGIN_BYTES))

  for dst in "$USB" "$HOST"; do
    avail_bytes=$(df -PB1 "$dst" | awk 'NR==2 {print $4}')
    echo "dst=$dst"
    echo "src_bytes=$src_bytes"
    echo "need_bytes_with_2GiB_margin=$need_bytes"
    echo "avail_bytes=$avail_bytes"
    if [ "$avail_bytes" -ge "$need_bytes" ]; then
      echo "space_ok=yes"
    else
      echo "space_ok=no"
    fi
    probe_dir="$dst/.codex-write-test-$(date +%Y%m%d%H%M%S)-$$"
    mkdir "$probe_dir" 2>/dev/null
    write_probe_exit=$?
    echo "write_probe_exit=$write_probe_exit"
    if [ "$write_probe_exit" -eq 0 ]; then
      printf 'ok\n' > "$probe_dir/probe.txt"
      echo "write_file_exit=$?"
      rm -f "$probe_dir/probe.txt"
      rmdir "$probe_dir"
    fi
  done

  echo "===== SCRIPT CHECK ====="
  test -f "$RUN/maildirpp_transport.py"; echo "maildirpp_script_exit=$?"
  python3 -m py_compile "$RUN/maildirpp_transport.py"; echo "compile_exit=$?"

  echo "===== FEDORA TRANSFER PREFLIGHT DONE ====="

Continue only if:

  manifest_exit=0
  inventory_exit=0
  part_count=21
  USB shows space_ok=yes, write_probe_exit=0, and write_file_exit=0
  host share shows host_share_mount_ok=yes, space_ok=yes, write_probe_exit=0, and write_file_exit=0 before using the Win11 host-share copy path
  compile_exit=0


Fedora USB Step - Copy verified export to USB
---------------------------------------------

Replace only this value with the real mounted USB path:

  USB="/run/media/$USER/YOUR_USB_LABEL"

COPY COMMAND:

  set +e

  export RUN="$HOME/codex-runs"
  export SRC="/home/atiq/maildirpp-archive-export-20260701-215204"
  export USB="/run/media/$USER/YOUR_USB_LABEL"
  export USB_EXPORT="$USB/maildirpp-archive-export-20260701-215204"
  export USB_SCRIPTS="$USB/codex-runs"

  echo "===== FEDORA USB COPY START ====="
  date

  mkdir -p "$USB_SCRIPTS" "$USB_EXPORT"

  cp -av "$RUN/maildirpp_transport.py" "$RUN/betterbird_profile_transport.py" "$USB_SCRIPTS/"
  sha256sum "$USB_SCRIPTS/maildirpp_transport.py" "$USB_SCRIPTS/betterbird_profile_transport.py"

  if command -v rsync >/dev/null 2>&1; then
    rsync -rt --partial --info=progress2 "$SRC/" "$USB_EXPORT/"
    COPY_EXIT=$?
  else
    cp -av "$SRC/." "$USB_EXPORT/"
    COPY_EXIT=$?
  fi

  echo "copy_exit=$COPY_EXIT"
  sync

  echo "===== USB COPY FILE CHECK ====="
  test -f "$USB_EXPORT/manifest.json"; echo "usb_manifest_exit=$?"
  test -f "$USB_EXPORT/inventory.jsonl"; echo "usb_inventory_exit=$?"

  python3 "$USB_SCRIPTS/maildirpp_transport.py" verify-archive \
    --manifest "$USB_EXPORT/manifest.json"
  echo "usb_verify_archive_exit=$?"

  echo "===== SYNC BEFORE UNPLUG ====="
  sync
  echo "If usb_verify_archive_exit=0, unmount/eject the USB safely before removing it."

  echo "===== FEDORA USB COPY DONE ====="

Expected success:

  copy_exit=0
  usb_manifest_exit=0
  usb_inventory_exit=0
  usb_part_count=21
  usb_verify_archive_exit=0

antiX Workflow - Validated Restore Chunk
========================================

Use this all-in-one restore chunk after the verified export package exists at:

  /mail/import-staging/maildirpp-archive-export-20260701-215204

This is safer than running fragmented commands because it prints the active
paths, compiles the copied script, rechecks the staged archive, refuses a
non-empty final destination, unpacks, verifies restored bytes, and runs a final
Maildir++ inspection in one logged operation.

Important:

  /mail/import-staging/maildirpp-archive-export-20260701-215204

is the transfer package. Do not unpack into that folder. The final restored
Maildir++ archive target is:

  /mail/Mailstore/evolution/local-maildir

COPY COMMAND:

  set +e

  export RUN="$HOME/codex-runs"
  export TRANSFER="/mail/import-staging/maildirpp-archive-export-20260701-215204"
  export MANIFEST="$TRANSFER/manifest.json"
  export DEST="/mail/Mailstore/evolution/local-maildir"

  echo "===== ANTIX RESTORE UNPACK VERIFY INSPECT START ====="
  date

  echo "===== PATH CHECK ====="
  echo "RUN=$RUN"
  echo "TRANSFER=$TRANSFER"
  echo "MANIFEST=$MANIFEST"
  echo "DEST=$DEST"
  ls -ld "$RUN" "$TRANSFER"
  df -h /mail "$TRANSFER"
  test -f "$RUN/maildirpp_transport.py"; echo "script_exit=$?"
  test -f "$MANIFEST"; echo "manifest_exit=$?"
  test -f "$TRANSFER/inventory.jsonl"; echo "inventory_exit=$?"
  echo "part_count=$(find "$TRANSFER" -maxdepth 1 -type f -name 'maildirpp-archive.tar.gz.part*' | wc -l)"
  sha256sum "$RUN/maildirpp_transport.py"

  echo "===== SCRIPT COMPILE CHECK ====="
  python3 -m py_compile "$RUN/maildirpp_transport.py"
  echo "compile_exit=$?"

  echo "===== VERIFY STAGED ARCHIVE BEFORE UNPACK ====="
  python3 "$RUN/maildirpp_transport.py" verify-archive --manifest "$MANIFEST"
  PRE_VERIFY_EXIT=$?
  echo "pre_unpack_verify_archive_exit=$PRE_VERIFY_EXIT"
  if [ "$PRE_VERIFY_EXIT" -ne 0 ]; then
    echo "ERROR: staged archive verification failed. Stop before unpack."
    exit 41
  fi

  echo "===== DESTINATION EMPTY CHECK ====="
  mkdir -p "$(dirname "$DEST")"
  if [ -e "$DEST" ] && [ "$(find "$DEST" -mindepth 1 -maxdepth 1 -print -quit 2>/dev/null)" ]; then
    echo "ERROR: destination is not empty: $DEST"
    echo "Stop here. Do not merge over an existing Maildir++ tree."
    exit 50
  fi

  echo "===== UNPACK TO FINAL MAILDIR++ DESTINATION ====="
  python3 "$RUN/maildirpp_transport.py" unpack --manifest "$MANIFEST" --dest "$DEST"
  UNPACK_EXIT=$?
  echo "unpack_exit=$UNPACK_EXIT"
  if [ "$UNPACK_EXIT" -ne 0 ]; then
    echo "ERROR: unpack failed. Stop before verify-tree."
    exit 42
  fi

  echo "===== DESTINATION QUICK CHECK ====="
  ls -ld "$DEST" "$DEST/cur" "$DEST/new" "$DEST/tmp"
  du -sh "$DEST"

  echo "===== VERIFY RESTORED TREE ====="
  python3 "$RUN/maildirpp_transport.py" verify-tree --manifest "$MANIFEST" --dest "$DEST"
  VERIFY_TREE_EXIT=$?
  echo "verify_tree_exit=$VERIFY_TREE_EXIT"
  if [ "$VERIFY_TREE_EXIT" -ne 0 ]; then
    echo "ERROR: verify-tree failed. Do not add to Evolution yet."
    exit 43
  fi

  echo "===== INSPECT RESTORED MAILDIR++ TREE ====="
  python3 "$RUN/maildirpp_transport.py" inspect --source "$DEST"
  INSPECT_EXIT=$?
  echo "inspect_exit=$INSPECT_EXIT"
  if [ "$INSPECT_EXIT" -ne 0 ]; then
    echo "ERROR: inspect failed. Do not add to Evolution yet."
    exit 44
  fi

  echo "===== ANTIX RESTORE UNPACK VERIFY INSPECT DONE ====="

Expected validated result:

  manifest_exit=0
  inventory_exit=0
  part_count=21
  compile_exit=0

  unpack_exit=0
  verify_tree_exit=0
  inspect_exit=0
  mode=unpack
  mode=verify-tree

Troubleshooting
===============

Problem: tmp-files-present

Meaning:

  A Maildir tmp directory contains payload files.

Action:

  Stop. A clean converted archive should have empty tmp directories. Inspect
  why the tmp file exists before packing.


Problem: missing cur/new/tmp

Meaning:

  The root or a Maildir++ dot folder is incomplete.

Action:

  Do not pack. Recheck the source path and conversion output.


Problem: SHA256 mismatch

Meaning:

  A transferred part or restored file changed.

Action:

  Re-transfer the affected part. If mismatch remains, repack on Fedora after
  confirming Evolution is stopped.


Problem: destination is not empty

Meaning:

  /mail/Mailstore/evolution/local-maildir already contains files.

Action:

  Do not merge by unpacking over it. Use a fresh destination or manually review
  and clear the path outside the script.


Problem: Evolution shows folders but no messages

Likely cause:

  The account was created as MH-format mail directories.

Action:

  Remove the account and recreate it as Maildir-format mail directories.
