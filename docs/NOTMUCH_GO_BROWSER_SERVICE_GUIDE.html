Go chi notmuch Browser Service for antiX

Read-only search/view service with automatic notmuch index refresh, localhost binding, local HTMX, compiled Tailwind CSS, and Windows SSH tunnel access.

Updated 2026-07-09. This HTML guide is offline-safe; commands are visible directly in each block and copy buttons only copy the visible command text.

This guide rebuilds the validated Go chi notmuch browser service on antiX Linux runit with zzzFM/IceWM. The service is search/view only. Evolution remains the reply, forward, compose, and send client.

  • Backend: Go net/http with github.com/go-chi/chi/v5, no Gin or Flask.
  • Frontend: modular embedded HTML templates, compiled local Tailwind CSS, and vendored local HTMX.
  • Bind address: 127.0.0.1:8765 inside antiX.
  • Windows access: SSH tunnel only.
  • No React, Node/npm/Tailwind runtime on antiX, CDN, uv runtime, or tmux supervisor.
  • notmuch database: /mail/SearchIndex/notmuch/default.
  • Mail root: /mail/Mailstore.
  • Safety flags: maildir.synchronize_flags=false, index.decrypt=false.
  • Full 59G archive remains excluded until count drift is explained or accepted.
Do not delete or rebuild Maildir data to fix browser search. Stale browser search errors are repaired through notmuch-browser-control refresh-index, which updates only the notmuch sidecar database.

Chunk 1: antiX Safety Audit

Run before building or changing the service.

antiX terminal
set -eu

CONFIG="$HOME/.config/notmuch/default/config"
MBSYNC_LOCK="/mail/AppData/isync/provider-live-loop/lock"

echo "== antiX notmuch browser safety audit =="
date -Is
echo

echo "== required commands =="
for c in go notmuch curl sh install; do
  if command -v "$c" >/dev/null 2>&1; then
    printf '%s=OK %s\n' "$c" "$(command -v "$c")"
  else
    printf '%s=MISSING\n' "$c"
  fi
done
echo

echo "== notmuch config safety =="
test -r "$CONFIG"
notmuch --config="$CONFIG" config get database.path
notmuch --config="$CONFIG" config get database.mail_root
notmuch --config="$CONFIG" config get maildir.synchronize_flags
notmuch --config="$CONFIG" config get index.decrypt
notmuch --config="$CONFIG" config get new.ignore
echo

echo "== notmuch counts =="
notmuch --config="$CONFIG" count '*'
notmuch --config="$CONFIG" count --output=files '*'
notmuch --config="$CONFIG" count tag:inbox
echo

echo "== locks and tmp files =="
test -d "$MBSYNC_LOCK" && echo "mbsync_lock=present" || echo "mbsync_lock=absent"
find /mail/Mailstore -type f -path '*/tmp/*' 2>/dev/null | wc -l | sed 's/^/maildir_tmp_files=/'
echo

echo "status=chunk1_safety_audit_complete"

Stop if database.path, database.mail_root, maildir.synchronize_flags, or index.decrypt differs from the validated values.

Chunk 5: Repair Stale notmuch Paths

Use this when browser search shows Error opening ... No such file or directory for indexed Maildir paths.

antiX terminal
set -eu

CONFIG="$HOME/.config/notmuch/default/config"
CONTROL="$HOME/.local/bin/notmuch-browser-control"
MBSYNC_LOCK="/mail/AppData/isync/provider-live-loop/lock"
STAMP="$(date +%Y%m%d-%H%M%S)"

echo "== stale index repair =="
date -Is
echo

echo "== before counts =="
notmuch --config="$CONFIG" count '*'
notmuch --config="$CONFIG" count --output=files '*'
notmuch --config="$CONFIG" count tag:inbox
echo

echo "== reproduce inbox metadata query =="
if notmuch --config="$CONFIG" show --format=json --entire-thread=false --body=false --offset=0 --limit=50 tag:inbox >/tmp/notmuch-before-"$STAMP".json 2>/tmp/notmuch-before-"$STAMP".err; then
  echo "before_query=OK"
else
  echo "before_query=FAILED"
  sed -n '1,80p' /tmp/notmuch-before-"$STAMP".err
fi
echo

echo "== refresh =="
if [ -d "$MBSYNC_LOCK" ]; then
  echo "status=blocked_mbsync_lock_present"
  exit 0
fi
"$CONTROL" refresh-index
echo

echo "== after query and browser =="
notmuch --config="$CONFIG" show --format=json --entire-thread=false --body=false --offset=0 --limit=50 tag:inbox >/tmp/notmuch-after-"$STAMP".json
wc -c /tmp/notmuch-after-"$STAMP".json
curl -fsS http://127.0.0.1:8765/healthz
echo
curl -fsS 'http://127.0.0.1:8765/search?q=tag%3Ainbox&offset=0&limit=10' >/tmp/notmuch-browser-after-repair.html
wc -c /tmp/notmuch-browser-after-repair.html
echo

echo "== tmp proof =="
find /mail/Mailstore -type f -path '*/tmp/*' 2>/dev/null | wc -l | sed 's/^/maildir_tmp_files=/'
echo

echo "status=chunk5_stale_index_repair_complete"
