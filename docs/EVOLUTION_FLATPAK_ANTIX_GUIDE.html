Purpose

This guide documents the confirmed working setup for installing Evolution from Flathub on an antiX 26 runit VM using zzzFM/IceWM on a Windows 11 host.

Verified target

org.gnome.Evolution from Flathub, version 3.60.2.

Primary storage

Mail, Evolution app data, cache, and migration targets live under /mail.

Do not point Evolution at the original Betterbird profile. Evolution must use a validated Maildir++ target, not a Betterbird profile tree.

Why Flatpak

Debian/antiX apt offered Evolution 3.56.x, while the desired upstream version was 3.60.x. Building from source was possible but required a large developer dependency set and careful matching of Evolution Data Server. Flatpak provided Evolution 3.60.2 with lower operational risk on a 2 CPU, 3.2 GiB RAM VM.

Decision: Use Flatpak Evolution as the preferred first Evolution path. Keep source-build as fallback.

Batch Script Pattern

For long command batches, use a reusable script and save a timestamped log.

Create script folder
mkdir -p ~/codex-runs
cd ~/codex-runs
nano codex-batch.sh
Reusable script template
#!/usr/bin/env bash
set -Eeuo pipefail

echo "== started: $(date -Is) =="
echo "== host: $(hostname) =="
echo

# Paste the command batch below this line.

echo
echo "== finished: $(date -Is) =="
Make executable and run with log
chmod +x ~/codex-runs/codex-batch.sh
bash -n ~/codex-runs/codex-batch.sh
~/codex-runs/codex-batch.sh 2>&1 | tee ~/codex-runs/codex-batch-$(date +%Y%m%d-%H%M%S).log

Simulate first. Proceed only if there are no removals or systemd conflicts.

Simulate support install

echo "== check for removals/errors =="
sudo apt -s install flatpak xdg-desktop-portal xdg-desktop-portal-gtk gnome-keyring seahorse \
  2>&1 | grep -E '^(Remv|Error|Unsatisfied|The following packages will be REMOVED|The following packages have unmet dependencies|Inst systemd|Inst libsystemd|Inst evolution)' || true
Install support packages
sudo apt install flatpak xdg-desktop-portal xdg-desktop-portal-gtk gnome-keyring seahorse
Verify support packages
echo "== flatpak installed =="
flatpak --version
flatpak remotes || true

echo "== keyring/portal tools =="
command -v gnome-keyring-daemon || true
command -v seahorse || true

echo "== session processes =="

pgrep -fa gnome-keyring || true

echo "== disk =="

Phase 3 - Flathub User Remote

Use user-level Flathub. The system-level remote failed on this antiX setup with ConfigureRemote not allowed for user.
Add Flathub for current user
flatpak --user remote-add --if-not-exists flathub https://flathub.org/repo/flathub.flatpakrepo
flatpak --user remotes --show-details
Inspect Evolution metadata
flatpak --user remote-info --log flathub org.gnome.Evolution | sed -n '1,220p'

Phase 4 - Install Evolution

Install Evolution Flatpak
flatpak --user install flathub org.gnome.Evolution
Verify Evolution install
echo "== installed flatpaks =="
flatpak --user list --app
flatpak --user list --runtime | sed -n '1,160p'

echo "== Evolution info =="
flatpak --user info org.gnome.Evolution

echo "== disk after Evolution Flatpak =="
df -hT / /mail
du -sh ~/.local/share/flatpak ~/.var/app/org.gnome.Evolution 2>/dev/null || true

Expected result: Evolution 3.60.2.

Phase 5 - /mail Access

Create layout and grant /mail access
echo "== create /mail Flatpak Evolution layout =="
mkdir -p /mail/AppData/flatpak-evolution
mkdir -p /mail/Mailstore/evolution/local-maildir
mkdir -p /mail/Mailstore/evolution/test-maildir

Phase 6 - Move App Data to /mail

Direct XDG_DATA_HOME, XDG_CONFIG_HOME, and XDG_CACHE_HOME Flatpak overrides were tested and did not take effect inside the sandbox. Use the symlink method.
Move app data and symlink it
set -eu

echo "== stop Evolution Flatpak cleanly =="
flatpak kill org.gnome.Evolution 2>/dev/null || true
sleep 3

echo "== stop leftover Evolution child processes if any =="
pkill -u "$USER" -f '^/app/libexec/evolution' 2>/dev/null || true
pkill -u "$USER" -f '^/app/libexec/evolution-data-server' 2>/dev/null || true
pkill -u "$USER" -f 'bwrap .*evolution' 2>/dev/null || true
sleep 3

echo "== remaining Evolution processes =="
pgrep -fa 'evolution|org.gnome.Evolution|bwrap' || true

echo "== remove ineffective XDG overrides =="
flatpak --user override org.gnome.Evolution --unset-env=XDG_DATA_HOME 2>/dev/null || true
flatpak --user override org.gnome.Evolution --unset-env=XDG_CONFIG_HOME 2>/dev/null || true
flatpak --user override org.gnome.Evolution --unset-env=XDG_CACHE_HOME 2>/dev/null || true

echo "== move Flatpak app data to /mail and symlink =="
APPID=org.gnome.Evolution
SRC="$HOME/.var/app/$APPID"
DST="/mail/AppData/flatpak-evolution/appdir"

mkdir -p "$HOME/.var/app"
mkdir -p /mail/AppData/flatpak-evolution

if [ -L "$SRC" ]; then
  echo "Already symlinked: $SRC -> $(readlink -f "$SRC")"
elif [ -e "$DST" ]; then
  echo "ERROR: destination already exists: $DST"
  exit 1
elif [ -e "$SRC" ]; then
  mv "$SRC" "$DST"
  ln -s "$DST" "$SRC"
else
  mkdir -p "$DST"
  ln -s "$DST" "$SRC"
fi

echo "== verify symlink =="
ls -ld "$SRC" "$DST"
readlink -f "$SRC"

echo "== verify Flatpak app data write goes through symlink to /mail =="
flatpak --user run --command=sh org.gnome.Evolution -lc '
echo "XDG_DATA_HOME=$XDG_DATA_HOME"
echo "XDG_CONFIG_HOME=$XDG_CONFIG_HOME"
echo "XDG_CACHE_HOME=$XDG_CACHE_HOME"
mkdir -p "$XDG_CACHE_HOME/evolution-test"
echo ok > "$XDG_CACHE_HOME/evolution-test/write-check"
cat "$XDG_CACHE_HOME/evolution-test/write-check"
'

echo "== host-side location check =="
ls -l /mail/AppData/flatpak-evolution/appdir/cache/evolution-test/write-check
du -shL "$HOME/.var/app/org.gnome.Evolution" /mail/AppData/flatpak-evolution/appdir
df -hT / /mail

Phase 9 - Configure Evolution Account

Launch Evolution and create a local Maildir account pointing at /mail/Mailstore/evolution/test-maildir.

Launch Evolution
gnome-keyring-daemon --start --components=secrets,pkcs11,ssh || true
flatpak --user run org.gnome.Evolution
Critical selection: choose Maildir-format mail directories. Do not choose MH-format mail directories. The wrong MH backend can show folders while hiding Maildir messages.
Verify backend
echo "== stop Evolution =="
flatpak kill org.gnome.Evolution 2>/dev/null || true
sleep 2

echo "== verify final test account backend =="
grep -RInE 'DisplayName=atiq@tagindustries.com.sg|BackendName=maildir|BackendName=mh|Path=/mail/Mailstore/evolution/test-maildir' \
  ~/.var/app/org.gnome.Evolution/config/evolution/sources \
  2>/dev/null || true

echo "== data location sizes =="
du -shL ~/.var/app/org.gnome.Evolution /mail/AppData/flatpak-evolution/appdir 2>/dev/null || true
du -sh /mail/Mailstore/evolution/test-maildir
df -hT / /mail

Correct result: BackendName=maildir and Path=/mail/Mailstore/evolution/test-maildir.

Maintenance, Backup, and Transfer

Bogofilter warning

If Evolution prints bogofilter wordlist.db errors, disable automatic junk filtering until spam/ham training is intentionally configured.

Update

Backup then update Evolution Flatpak
flatpak kill org.gnome.Evolution 2>/dev/null || true
mkdir -p /mail/Backups/evolution-flatpak
tar -C /mail/AppData/flatpak-evolution -czf /mail/Backups/evolution-flatpak/appdir-before-flatpak-update-$(date +%Y%m%d-%H%M%S).tar.gz appdir
flatpak --user update org.gnome.Evolution
flatpak --user info org.gnome.Evolution

Transfer to another machine

Restore /mail/AppData/flatpak-evolution/appdir and /mail/Mailstore/evolution, reinstall the Flatpak, recreate the symlink, and grant /mail access.

Recreate symlink and /mail access
mkdir -p "$HOME/.var/app"
rm -rf "$HOME/.var/app/org.gnome.Evolution"
ln -s /mail/AppData/flatpak-evolution/appdir "$HOME/.var/app/org.gnome.Evolution"
flatpak --user override org.gnome.Evolution --filesystem=/mail:create

Troubleshooting

ProblemFix
System Flathub remote fails with ConfigureRemote not allowed.Use flatpak --user remote-add.
Evolution does not appear in IceWM menu.Launch with flatpak --user run org.gnome.Evolution; restart the session later for menu integration.
Folders visible but messages missing.Remove the account and recreate it as Maildir-format mail directories, not MH.
Data appears under ~/.var/app.Expected if it is a symlink. Verify with readlink -f ~/.var/app/org.gnome.Evolution.
Bogofilter errors.Disable junk filtering until training is configured.
