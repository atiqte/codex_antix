Betterbird Post-Main-Archive Aggregate Delta Guide
=====================================================

Purpose
-------

This guide replaces the old fixed-count Betterbird delta flow with a dynamic post-main-archive aggregate delta. Each run selects every Betterbird source message absent from the main converted archive baseline, even if the command is run days later.

Baseline Model
--------------

The baseline is the original converter state database at /home/atiq/Evolution-Mailstore/betterbird-archive-maildirpp/.conversion-state.sqlite. That state corresponds to the main archive export maildirpp-archive-export-20260701-215204. The workflow does not use email Date headers as the boundary.

Safety Rules
------------

Close Betterbird and Evolution before staging, conversion, packing, or restore. Never overwrite an existing staging, target, export, or antiX destination directory. Keep each aggregate separate from /mail/Mailstore/evolution/local-maildir and /mail/Mailstore/mbsync/provider-live.

Prerequisites
-------------

Before Batch 1, copy these three repository scripts to Fedora ~/codex-runs with the same filenames: src/betterbird_post_archive_delta.py, src/betterbird_maildirlite_to_maildirpp.py, and src/maildirpp_transport.py. Batch 1 verifies they exist and compile before touching any mail data.

Start Here - Dynamic Batches
----------------------------

Run one batch at a time. Batch 1 creates a RUN_ID and writes it to ~/codex-runs/post-main-archive-run-id.txt; later Fedora batches reuse that same RUN_ID.

Batch 1: Fedora Audit
~~~~~~~~~~~~~~~~~~~~~

```bash
echo "=== Post-main-archive aggregate delta: Batch 1 audit ==="
date -Is
hostnamectl 2>/dev/null || true
python3 --version

RUN="$HOME/codex-runs"
POST="$RUN/betterbird_post_archive_delta.py"
CONVERTER="$RUN/betterbird_maildirlite_to_maildirpp.py"
TRANSPORT="$RUN/maildirpp_transport.py"
RUN_ID="$(date +%Y%m%d-%H%M%S)"
RUN_ID_FILE="$RUN/post-main-archive-run-id.txt"

mkdir -p "$RUN"
printf '%s
' "$RUN_ID" > "$RUN_ID_FILE"
echo "run_id=$RUN_ID"
echo "run_id_file=$RUN_ID_FILE"

for script in "$POST" "$CONVERTER" "$TRANSPORT"; do
  test -f "$script" || { echo "ERROR: missing script $script"; exit 1; }
done
python3 -m py_compile "$POST" "$CONVERTER" "$TRANSPORT"

pgrep -a -f 'betterbird|thunderbird|evolution' || echo "no matching mail processes found"
python3 "$POST" audit --run-id "$RUN_ID"
```

Batch 2: Stop Mail Processes
~~~~~~~~~~~~~~~~~~~~~~~~~~~~

```bash
echo "=== Post-main-archive aggregate delta: Batch 2 stop mail processes ==="
date -Is

flatpak kill org.gnome.Evolution >/dev/null 2>&1 || true
if command -v evolution >/dev/null 2>&1; then
  evolution --force-shutdown >/dev/null 2>&1 || true
fi

for name in evolution-source-registry evolution-alarm-notify evolution-calendar-factory evolution-addressbook-factory; do
  pkill -TERM -u "$USER" -x "$name" 2>/dev/null || true

pkill -TERM -u "$USER" -f '^/app/libexec/evolution-' 2>/dev/null || true

  echo "status=blocked_mail_processes_still_running"

else
  echo "status=no_mail_processes_running"
fi
```

Batch 5: Copy And Verify
~~~~~~~~~~~~~~~~~~~~~~~~

```bash
echo "=== Post-main-archive aggregate delta: Batch 5 copy and verify ==="
date -Is

RUN="$HOME/codex-runs"
CONVERTER="$RUN/betterbird_maildirlite_to_maildirpp.py"
RUN_ID="$(cat "$RUN/post-main-archive-run-id.txt")"
STAGING="$HOME/Evolution-Mailstore/post-main-archive-work/$RUN_ID/staging-betterbird-maildir"
TARGET="$HOME/Evolution-Mailstore/betterbird-post-main-archive-maildirpp-$RUN_ID"

echo "run_id=$RUN_ID"
test -d "$STAGING" || { echo "ERROR: staging missing $STAGING"; exit 1; }
test ! -e "$TARGET" || { echo "ERROR: target already exists $TARGET"; exit 1; }
python3 -m py_compile "$CONVERTER"

python3 "$CONVERTER" --source "$STAGING" --target "$TARGET" --log-dir "$LOGDIR" --copy --resume
COPY_EXIT=$?
echo "copy_exit=$COPY_EXIT"
test "$COPY_EXIT" -eq 0 || exit "$COPY_EXIT"
python3 "$CONVERTER" --source "$STAGING" --target "$TARGET" --log-dir "$LOGDIR" --verify --verify-hash
VERIFY_EXIT=$?
echo "verify_exit=$VERIFY_EXIT"
echo "target_cur_count=$(find "$TARGET" -path '*/cur/*' -type f | wc -l)"
echo "target_new_count=$(find "$TARGET" -path '*/new/*' -type f | wc -l)"
echo "target_tmp_count=$(find "$TARGET" -path '*/tmp/*' -type f | wc -l)"
du -sh "$TARGET"
exit "$VERIFY_EXIT"
```

Batch 8: antiX Stage From ZIP
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

```bash
echo "=== Post-main-archive aggregate delta: Batch 8 antiX stage from ZIP ==="
date -Is

export RUN_ID="PASTE_RUN_ID_HERE"
ZIP="$HOME/Downloads/maildirpp-post-main-archive-export-$RUN_ID.zip"
RUN="$HOME/codex-runs"
TRANSPORT="$RUN/maildirpp_transport.py"
STAGING_PARENT="/mail/import-staging"
TRANSFER="$STAGING_PARENT/maildirpp-post-main-archive-export-$RUN_ID"
DEST="/mail/Mailstore/evolution/betterbird-post-main-archive-maildirpp-$RUN_ID"

echo "run_id=$RUN_ID"
test -f "$ZIP" || { echo "ERROR: ZIP missing $ZIP"; exit 1; }
test -f "$TRANSPORT" || { echo "ERROR: transport script missing $TRANSPORT"; exit 1; }
test ! -e "$TRANSFER" || { echo "ERROR: transfer staging exists $TRANSFER"; exit 1; }
test ! -e "$DEST" || { echo "ERROR: destination exists $DEST"; exit 1; }
python3 -m py_compile "$TRANSPORT"
mkdir -p "$STAGING_PARENT"
python3 - <<'PY'
from pathlib import Path
import os
import sys
import zipfile
run_id = os.environ.get('RUN_ID', 'PASTE_RUN_ID_HERE')
zip_path = Path.home() / 'Downloads' / f'maildirpp-post-main-archive-export-{run_id}.zip'
staging_parent = Path('/mail/import-staging')
expected_top = f'maildirpp-post-main-archive-export-{run_id}'
target = staging_parent / expected_top
with zipfile.ZipFile(zip_path) as z:
    bad = z.testzip()
    if bad is not None:
        raise SystemExit(f'bad_zip_member={bad}')
    names = [name for name in z.namelist() if name and not name.endswith('/')]
    tops = {name.split('/', 1)[0] for name in names}
    if tops != {expected_top}:
        raise SystemExit(f'unexpected_zip_top={tops}')
    for info in z.infolist():
        if info.is_dir():
            continue
        out = staging_parent / info.filename
        if target not in out.parents:
            raise SystemExit(f'unsafe_zip_path={info.filename}')
        out.parent.mkdir(parents=True, exist_ok=True)
        with z.open(info, 'r') as src, out.open('xb') as dst:
            import shutil
            shutil.copyfileobj(src, dst, length=1024 * 1024)
print(f'extracted_to={target}')
print('status=extract_ok')
PY
python3 "$TRANSPORT" verify-archive --manifest "$TRANSFER/manifest.json"
```

Batch 9: antiX Restore And Inspect
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

```bash
echo "=== Post-main-archive aggregate delta: Batch 9 antiX restore and inspect ==="
date -Is

RUN_ID="PASTE_RUN_ID_HERE"
RUN="$HOME/codex-runs"
TRANSPORT="$RUN/maildirpp_transport.py"
TRANSFER="/mail/import-staging/maildirpp-post-main-archive-export-$RUN_ID"
DEST="/mail/Mailstore/evolution/betterbird-post-main-archive-maildirpp-$RUN_ID"

echo "run_id=$RUN_ID"
flatpak kill org.gnome.Evolution >/dev/null 2>&1 || true
if pgrep -a -u "$USER" -f 'evolution|/app/libexec/evolution|bwrap.*evolution'; then
  echo "ERROR: Evolution still running"
  exit 1
fi

test -f "$TRANSFER/manifest.json" || { echo "ERROR: manifest missing"; exit 1; }
test ! -e "$DEST" || { echo "ERROR: destination exists $DEST"; exit 1; }
python3 -m py_compile "$TRANSPORT"
python3 "$TRANSPORT" verify-archive --manifest "$TRANSFER/manifest.json"
python3 "$TRANSPORT" unpack --manifest "$TRANSFER/manifest.json" --dest "$DEST"
python3 "$TRANSPORT" verify-tree --manifest "$TRANSFER/manifest.json" --dest "$DEST"
python3 "$TRANSPORT" inspect --source "$DEST"
echo "restore_target=$DEST"
```

Evolution Handling
------------------

Add the new aggregate target as Maildir-format mail directories. After the newer aggregate is validated, disable or remove older post-main-archive delta accounts from Evolution to avoid duplicate search results. Do not delete old delta files until backup and cleanup are explicitly planned.

Acceptance Checks
-----------------

- Batch 1 reports baseline_copied_rows=48720 and a dynamic post_archive_candidate_count.
- Batch 3 reports status=staging_ready, with staged cur/new counts matching Batch 1.
- Batch 5 reports copy_exit=0, verify_exit=0, and target_tmp_count=0.
- Batch 6 verifies the portable export before any transfer.
- Batch 9 verifies archive, restored tree, and Maildir++ inspection on antiX before Evolution is opened.
