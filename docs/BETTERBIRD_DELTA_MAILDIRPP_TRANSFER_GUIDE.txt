Betterbird after the first full Betterbird maildir-lite to Maildir++ conversion.

separate Evolution Maildir account.

Safety Rules
------------

- Close Betterbird and Evolution before conversion, packing, or restore.
- Keep the delta archive separate from the old 59G archive.
- Keep the delta archive separate from mbsync provider-live.
- Never unpack over an existing final destination.
- Verify the archive before transfer, after transfer, and before unpack.
- Run verify-tree and inspect after unpack.
- Add the final directory to Evolution as Maildir-format mail directories.
- Do not choose MH-format mail directories.

Phase 4A - USB Transfer Path
----------------------------

Use this if a USB drive is mounted and writable on Fedora.

Replace YOUR_USB_LABEL with the real mount label:

  USB="/run/media/$USER/YOUR_USB_LABEL"
  SRC="$HOME/maildirpp-delta-export-20260704-151448"
  RUN="$HOME/codex-runs"
  USB_EXPORT="$USB/maildirpp-delta-export-20260704-151448"
  USB_SCRIPTS="$USB/codex-runs"

  ls -ld "$USB" "$SRC"
  df -h "$USB" "$SRC"

  PROBE="$USB/codex-delta-transfer-probe-$(date +%Y%m%d-%H%M%S)"
  mkdir "$PROBE"
  printf 'probe\n' > "$PROBE/probe.txt"
  rm -f "$PROBE/probe.txt"
  rmdir "$PROBE"

  test ! -e "$USB_EXPORT" || { echo "ERROR: USB export already exists"; exit 1; }

  mkdir -p "$USB_SCRIPTS" "$USB_EXPORT"
  cp -av "$RUN/maildirpp_transport.py" "$USB_SCRIPTS/"
  sha256sum "$RUN/maildirpp_transport.py" "$USB_SCRIPTS/maildirpp_transport.py"

  if command -v rsync >/dev/null 2>&1; then
    rsync -rt --partial --info=progress2 "$SRC/" "$USB_EXPORT/"
  else
    cp -av "$SRC/." "$USB_EXPORT/"
  fi

  test -f "$USB_EXPORT/manifest.json"; echo "usb_manifest_exit=$?"
  test -f "$USB_EXPORT/inventory.jsonl"; echo "usb_inventory_exit=$?"
  echo "usb_part_count=$(find "$USB_EXPORT" -maxdepth 1 -type f -name 'maildirpp-archive.tar.gz.part*' | wc -l)"

  python3 "$USB_SCRIPTS/maildirpp_transport.py" verify-archive \
    --manifest "$USB_EXPORT/manifest.json"
  echo "usb_verify_archive_exit=$?"

  sync

Expected success:

  usb_manifest_exit=0
  usb_inventory_exit=0
  usb_part_count=1
  usb_verify_archive_exit=0
  status=ok

Safely eject/unmount the USB before removing it.

Phase 5 - antiX Staging From ZIP
--------------------------------

Run in antiX terminal:

  ZIP="$HOME/Downloads/maildirpp-delta-export-20260704-151448.zip"
  RUN="$HOME/codex-runs"
  SCRIPT="$RUN/maildirpp_transport.py"
  STAGING_PARENT="/mail/import-staging"
  TRANSFER="$STAGING_PARENT/maildirpp-delta-export-20260704-151448"
  DEST="/mail/Mailstore/evolution/betterbird-delta-maildirpp-20260704"

  test -f "$ZIP" || { echo "ERROR: ZIP missing"; exit 1; }
  test -f "$SCRIPT" || { echo "ERROR: transport script missing"; exit 1; }
  python3 -m py_compile "$SCRIPT"
  test ! -e "$TRANSFER" || { echo "ERROR: staging already exists"; exit 1; }
  test ! -e "$DEST" || { echo "ERROR: final destination already exists"; exit 1; }

  python3 - <<'PY'
from pathlib import Path, PurePosixPath
import shutil
import zipfile

zip_path = Path.home() / "Downloads" / "maildirpp-delta-export-20260704-151448.zip"
staging_parent = Path("/mail/import-staging")
expected_top = "maildirpp-delta-export-20260704-151448"
target = staging_parent / expected_top

if target.exists():
    print("extract_status=blocked_target_exists")
    raise SystemExit(1)

with zipfile.ZipFile(zip_path) as z:
    bad = z.testzip()
    print(f"zip_testzip_bad_entry={bad if bad else 'NONE'}")
    if bad:
        raise SystemExit(2)
    names = [i.filename for i in z.infolist()]
    top_levels = sorted(set(n.split("/", 1)[0] for n in names if n))
    print("zip_top_level_entries=" + "|".join(top_levels))
    if top_levels != [expected_top]:
        print("extract_status=blocked_unexpected_top_level")
        raise SystemExit(3)
    for info in z.infolist():
        pp = PurePosixPath(info.filename)
        if pp.is_absolute() or ".." in pp.parts:
            print(f"extract_status=blocked_unsafe_path:{info.filename}")
            raise SystemExit(4)
    for info in z.infolist():
        pp = PurePosixPath(info.filename)
        out_path = staging_parent.joinpath(*pp.parts)
        if info.is_dir():
            out_path.mkdir(parents=True, exist_ok=True)
            continue
        out_path.parent.mkdir(parents=True, exist_ok=True)
        with z.open(info, "r") as src, out_path.open("xb") as dst:
            shutil.copyfileobj(src, dst, length=1024 * 1024)

print(f"extracted_to={target}")
print("extract_status=ok")
PY

  test -f "$TRANSFER/manifest.json"; echo "staging_manifest_exit=$?"
  test -f "$TRANSFER/inventory.jsonl"; echo "staging_inventory_exit=$?"
  echo "staging_part_count=$(find "$TRANSFER" -maxdepth 1 -type f -name 'maildirpp-archive.tar.gz.part*' | wc -l)"

  python3 "$SCRIPT" verify-archive --manifest "$TRANSFER/manifest.json"
  echo "staging_verify_archive_exit=$?"

Validated result:
